Gun camera · in-engine capture

Up there, you're the only air support they have.

A top-down arcade shooter with real flight momentum. Your jet never stops moving, so every strafing run and bomb drop is about lining up the approach.

  1. Clear the sky

    Quad cannons fire four rounds per trigger pull. Homing rockets lock on through a forward cone radar or a close 360° scan.

  2. Cover the squad

    Fireteam Viper fights on the ground below you. When they get pinned, they call a strike on a beacon. Deliver it for +500 points.

  3. Bring them home

    Hold the line until Pelican-1 lands, then keep the landing zone clear while your squad boards. A clean extraction pays +2,500.

      Enlistment · Windows

      Three steps to your first sortie.

      No account, no launcher, no installer. Standalone package with the game inside.

      1. Download

        Get Eagle-1-Windows.zip from the latest release (39 MB).

      2. Extract

        Right-click the zip and choose Extract All. Keep the folder together: the game reads its images, audio and save data from it.

      3. Launch

        Open the Eagle-1 folder and double-click Eagle-1.exe. Press Shift on the main menu to start.

      Blue "Windows protected your PC" box? The game is not code-signed yet, so SmartScreen warns about it. Click More info, then Run anyway.

      1. Download

        Get Eagle-1-macOS.zip (42 MB) or the Eagle-1-macOS.dmg disk image.

      2. Install

        Unzip the archive (or open the disk image) and drag Eagle-1.app into your /Applications folder.

      3. Launch

        Open Eagle-1.app. On first launch, macOS Gatekeeper may prompt verification for unsigned indie games: right-click and choose Open, or run xattr -d com.apple.quarantine /Applications/Eagle-1.app in Terminal.

      High-DPI Retina Ready: Native high-resolution graphics and 60 FPS flight dynamics on Apple Silicon and Intel Macs.

      1. Download

        Get Eagle-1-Linux.tar.gz from the latest release (41 MB).

      2. Extract

        Extract the tarball in terminal: tar -xzf Eagle-1-Linux.tar.gz.

      3. Launch

        Run ./Eagle-1/Eagle-1 or double-click the binary from your file manager.

      Prerequisites: Requires standard SDL2 libraries. If needed on Ubuntu/Debian: sudo apt install libsdl2-2.0-0 libsdl2-mixer-2.0-0.

      Run from source on any OS with Python

      You need Python 3.9 or newer. Paste this into a terminal:

      git clone https://github.com/paulp143/Eagle-1-64Bit.git
cd Eagle-1-64Bit
pip install -r requirements.txt
python run_game.py
