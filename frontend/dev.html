TECHNICAL SPECIFICATIONS

Subsystem architecture designed for modular expansion and deterministic combat physics.

01 // COORDINATE GRIDS

Strict separation between World Space (3000×3000 pixel battlefield) and Screen Space (1280×720 clamped viewport) tracking the player aircraft.

02 // AUDIO ARCHITECTURE

16-channel centralized mixer. Procedural audio waveform synthesis (44.1kHz stereo PCM) generated via generate_audio_assets.py with real-time thruster frequency modulation.

03 // FLIGHT & BALLISTICS

Continuous inertia flight with W/S throttle and A/D angular deflection. Predictive aiming reticle dynamically calculates bomb lead: 320.0 + (velocity × 8.0).

04 // HELLDIVER SQUAD AI

Autonomous ground team (Viper 1-4) with state machines for objective assault, emergency supply pod pathfinding, anti-air fire, and Pelican-1 extraction boarding.

05 // CI/CD BUILD PIPELINE

Automated standalone Windows binary packaging via PyInstaller in GitHub Actions, uploading releases and deploying static sites via GitHub Pages.

06 // EXTENSIBLE ORDNANCE

Modular stratagem system configured with independent cooldown timers, sound profiles, and blast radiuses in ground_support.py.
